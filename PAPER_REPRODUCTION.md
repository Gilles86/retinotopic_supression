# Reproducing the retsupp paper

Paper result → code map for the n = 28 manuscript (numbers in `notes/writing_package_2026-11-12_update4_final/key_numbers.md`,
with the gain-field numbers superseded by `notes/writing_package_2026-11-12_update8/key_numbers.md` and
`key_numbers_reference_full.md` there; figures in `notes/figures/paper_2026-11/`; sub-01 and sub-02 are left out).
Every number in those `key_numbers.md` files names its source table; this file names the code.

**Reference gain-field fit (update 8, provisional until the voxel-selection check is decided):** DoG ladder with the pRFs
refitted together with the gain fields, `derivatives/af_prf_cv_ladder_nested_full_bounded_maxsd20_reliable_roihrf_polished`
(m4_TDS, m7_full; the other models from `..._reliable_roihrf`), terms estimated alone in
`derivatives/af_fixed_group_mechanisms_polished_2026-11-12`; tables `notes/data/gain_field_parameters_polished_2026-11-12.tsv`,
`notes/data/conditional_estimates_polished_2026-11-12.tsv` (rows `valid`), widths
`notes/data/field_widths_reliable_polished_2026-11-12_n28_*.tsv`. Items and the T, D, S gains come from the joint fit
(m7_full) only; dS, dD, dT estimated alone from the refitted m4_TDS. Gaussian and DN robustness fits, LOSO, κ and split
models, per-session dS and the trial-wise gains still use the fits with the pRFs held fixed. Every Fig. 5 output and the
key numbers for a reference root are regenerated by `retsupp/visualize/paper/regenerate_reference.sh`
(`cluster-submit`, `cluster-collect`, `local`; the root is the `REF_ROOT` / `ALONE_FOLDER` / `TAG` / `SUFFIX` variables). Code and notes that the paper does not need were moved to `archive/paper_cleanup_2026-11-12/` (see its README).

Data: BIDS dataset `ds-retsupp` (cluster `/shares/zne.uzh/gdehol/ds-retsupp`, local `/data/ds-retsupp`). Data access
goes through `retsupp/utils/data.py` (`Subject`). Cluster scripts: account `hare.econ.uzh`, submit as
`VAR=x sbatch ...` (no `--export` lists). Environments: `retsupp_cuda` (cluster), `retsupp` (local),
`bauer` (Bayesian RT models), `pycortex2` (cortical renders).
